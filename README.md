# AI 学习助手（暂定名）

面向九年级学生的数学、物理智能学习伴侣。第一阶段目标是验证“拍题 → 规范解析 → 同类练习 → 掌握反馈”的学习闭环。

## 当前结构

- `apps/student/`：学生端 Taro 项目，后续同时构建微信小程序和 H5。
- `apps/api/`：后端服务，负责图片、AI 调用、学习记录与后续计费。
- `packages/shared/`：前后端共用的数据类型与接口契约。
- `infra/`：本地 PostgreSQL 与后续部署配置。
- `docs/`：产品、接口与运维文档。

## 本地启动前提

1. 复制 `.env.example` 为 `.env.local`，再填写真实的本地配置；
2. 安装并启动 Docker Desktop 后运行 `pnpm db:up`；
3. 初始化完成学生端依赖后运行 `pnpm dev:student`；
4. 在微信开发者工具中导入学生端构建产物进行调试。

详细规划见根目录的《第一阶段规划.md》和《开发环境与部署准备.md》。
